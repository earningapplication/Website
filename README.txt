CLIENT BUSINESS BOOKING WEBSITE — DEMO
======================================

Open index.html in any modern browser.

WHAT IS INCLUDED
- Premium responsive landing page
- Services + editable demo prices
- Date + time booking form
- Customer name + phone + notes
- Local demo booking storage (localStorage)
- Google Maps button using the client URL supplied
- Reviews section ready for real Google reviews
- Gallery ready for real business photos
- Mobile responsive design
- No backend required for this demo

IMPORTANT
The supplied Google Maps short URL could not be reliably fetched by the current environment, so the demo intentionally does not claim or copy real business details/reviews/photos. Replace the placeholders with client-approved material before publishing.
